# PLUZ-ps5 (PayLoadUpdaterZ-PS5)

A personal, pldmgr-compatible payload mirror and manifest generator for PS5 homebrew.

- `payload_registry.json` is the source of truth for every payload entry.
- New payloads are added via the "Add Payload" Issue form (no manual JSON editing).
- `manifests/` holds the generated PLDMGR-compatible output (main + hosted tiers).

See the repo's Issues tab -> New Issue -> "Add Payload" to add an entry.
